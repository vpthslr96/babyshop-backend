# babyshop-backend

REST API для интернет-магазина детской одежды. Фронтенд: [babyshop](https://github.com/vpthslr96/babyshop).

## Стек

- **NestJS 11** + TypeScript
- **PostgreSQL** + TypeORM
- **JWT**-аутентификация администратора (пароль хранится как bcrypt-хеш)
- class-validator для валидации входящих данных
- Загрузка изображений товаров (multer), раздача статики из `/uploads`

## Возможности

**Каталог товаров**
- Поиск и фильтрация: тип одежды, состояние, пол, сезон, размер, диапазон цен
- Сортировка: новые, по возрастанию и убыванию цены
- Пагинация

**Заказы**
- Оформление заказа покупателем без регистрации
- Просмотр, изменение статуса и отмена заказов (для администратора)

**Админ-панель**
- CRUD товаров
- Загрузка нескольких фото к товару, выбор главного фото, удаление

## API

| Метод | Путь | Доступ | Описание |
|---|---|---|---|
| POST | `/auth/login` | все | Вход администратора, возвращает JWT |
| GET | `/products` | все | Список товаров с фильтрами и пагинацией |
| GET | `/products/:id` | все | Карточка товара |
| POST | `/products` | админ | Создать товар |
| PATCH | `/products/:id` | админ | Изменить товар |
| DELETE | `/products/:id` | админ | Удалить товар |
| POST | `/products/:id/images` | админ | Загрузить фото |
| DELETE | `/products/:id/images/:imageId` | админ | Удалить фото |
| PATCH | `/products/:id/images/:imageId/primary` | админ | Сделать фото главным |
| POST | `/orders` | все | Оформить заказ |
| GET | `/orders` | админ | Список заказов |
| PATCH | `/orders/:id` | админ | Изменить заказ |
| PATCH | `/orders/:id/cancel` | админ | Отменить заказ |

Защищённые эндпоинты требуют заголовок `Authorization: Bearer <token>`.

## Запуск локально

Нужны Node.js 20+ и PostgreSQL.

```bash
npm install
cp .env.example .env
```

Заполни `.env`:

| Переменная | Описание |
|---|---|
| `PORT` | Порт API (по умолчанию 3001) |
| `CORS_ORIGIN` | Адрес фронтенда, можно несколько через запятую |
| `DB_HOST`, `DB_PORT`, `DB_USERNAME`, `DB_PASSWORD`, `DB_NAME` | Подключение к PostgreSQL |
| `JWT_SECRET` | Любая длинная случайная строка |
| `ADMIN_PASSWORD_HASH` | bcrypt-хеш пароля администратора |

Хеш пароля можно получить так:

```bash
node hash-password.js <пароль>
```

Создай базу данных и запусти сервер:

```bash
createdb babyshop
npm run start:dev
```

Таблицы создаются автоматически при старте (TypeORM `synchronize`).

### Демо-данные

Когда сервер запущен, можно наполнить каталог сотней тестовых товаров с картинками:

```bash
node scripts/seed-demo-data.js
```
